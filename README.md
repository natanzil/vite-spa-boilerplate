# Vite SPA Boilerplate

A minimal boilerplate for creating single page applications with Vite.

## Features

- ⚡️ Lightning fast development with Vite
- 📦 Minimal setup and configuration
- 🔥 Hot Module Replacement (HMR)
- 🎨 Modern CSS with dark/light mode support
- 📱 Responsive design

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/natanzil/vite-spa-boilerplate.git
cd vite-spa-boilerplate
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:3000`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Project Structure

```
├── index.html          # Entry HTML file
├── main.js            # Main JavaScript file
├── style.css          # Global styles
├── vite.config.js     # Vite configuration
└── package.json       # Project dependencies and scripts
```

## Customization

This boilerplate provides a minimal foundation. You can extend it by:

- Adding your favorite CSS framework
- Installing additional dependencies
- Setting up routing (e.g., with vanilla router or your preferred solution)
- Adding state management
- Integrating with APIs
